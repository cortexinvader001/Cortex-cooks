# Cortex Cooks: image prompts

Six photos fill the six placeholder slots on the site. Paste each prompt into an image generator
(Midjourney, Gemini, ChatGPT images, Ideogram or Flux). Each prompt has two variants, so generate both and keep the better one.

**How to add them:** save each file in `public/images/` with exactly these names. Use `.jpg`, `.webp`, `.avif` or `.png`.
The site picks them up automatically and the placeholder disappears.

| # | File name | Where it appears | Ratio |
|---|---|---|---|
| 1 | `hero.jpg` | Top of the page, right side, diagonal crop | 4:3 |
| 2 | `grill.jpg` | Menu, Grill row | 4:3 |
| 3 | `fries.jpg` | Menu, Fries row | 4:3 |
| 4 | `chicken.jpg` | Menu, Chicken row | 4:3 |
| 5 | `cocktails.jpg` | Menu, Cocktails row | 4:3 |
| 6 | `smoothies.jpg` | Menu, Smoothies row | 4:3 |

Palette used in every prompt: charcoal black, ember orange and warm cream, to match the site.

**Tip:** if you have real photos of your own dishes, use those instead. AI images can show food you don't actually serve.
Keep each file under about 200 KB for the hero and 120 KB for the rest (squoosh.app is free and fast).

## Adjusting a result

Change one thing at a time. If the crop is wrong, adjust only the crop line. If the light is too cold, add "warm golden light". If the colors drift, repeat the palette line at the end.
